## Import

```ts
import { createRouter, defineRoutes } from '@cookbook/router';
```

The package exposes one public root entrypoint. `RouteView` is `unknown`; framework adapters decide how views render.

## Runtime guarantees

Routes are validated before normalization. Route-ID href generation validates required params and path constraints before history changes. Matching parses params, search, hash, and unknown search state through URLKit. Disposal is terminal.

## Where this bites

The package does not render React, discover files, or generate TypeScript. Those responsibilities belong to [`@cookbook/router-react`](/docs/router/api/router-react) and [`@cookbook/router-cli`](/docs/router/api/router-cli).
