Core contracts are the root type surface exported by `@cookbook/router`.

They define generated route registration, route-indexed URL state, authored routes, normalized routes, matches, middleware, lifecycle hooks, slots, intercepts, metadata, runtime state, history state, URL policy, path options, rendering callbacks, and serialization.

There is no public `@cookbook/router/contracts` subpath. Import these contracts from the package root or from their owning subpath.

## Generated registration

```ts
interface Register {}
```

`Register` is the module-augmentation hook used by generated route contracts.

The generated `register.d.ts` augments it with a concrete `contracts` property:

```ts
interface Register {
  contracts: RouterContracts;
}
```

Without augmentation, router APIs remain permissive.

## `RegisteredContracts`

```ts
type RegisteredContracts =
  Register extends {
    contracts: infer Contracts;
  }
    ? Contracts
    : RouterContracts;
```

`RegisteredContracts` is the active contract model after module augmentation.

When no generated registration exists, it falls back to the permissive `RouterContracts` shape.

Parsed and input contracts differ deliberately.

Defaulted search fields are present after parsing but optional while building. Wildcard path input accepts a slash-delimited string or primitive segment array. Parsed wildcard params are readonly string arrays.

## `RouteUrlOptions`

```ts
interface RouteUrlOptions<Route extends string> {
  readonly params?: RouteParamsInput<Route>;
  readonly search?: RouteSearchInput<Route>;
  readonly hash?: RouteHashInput<Route>;
}
```

`RouteUrlOptions` is the generated per-route URL-state input shared by href generation, route resolution, navigation, preloading, and React link contracts.

It is not the same as `RouterUrlOptions`.

| Contract                 | Purpose                                                                                       |
| ------------------------ | --------------------------------------------------------------------------------------------- |
| `RouteUrlOptions<Route>` | Per-route typed params/search/hash input.                                                     |
| `RouterUrlOptions`       | Runtime URL policy: array format, defaults, invalid state, unknown search, and path matching. |

## Authored route contracts

```ts
type RouteView = unknown;

type RouteMeta = Record<string, unknown>;

type RouteSearchSchema =
  Readonly<Record<string, StaticSearchField>>;

type RouteHashSchema = StaticHashDescriptor;
```

`RouteView` is opaque. The core router never calls it. Rendering integrations decide what a view means.

`RouteMeta` is application-owned data. The core router copies it through authored, normalized, and matched state but does not interpret it.

## Redirect contracts

```ts
type RouteRedirect =
  | string
  | {
      readonly route: string;
      readonly params?: Record<string, unknown>;
      readonly search?: Record<string, unknown>;
      readonly hash?: string | null;
    };
```

A string redirect is a literal href. An object redirect targets a route ID and builds an href from params, search, and hash.

## Interception contracts

```ts
interface RouteInterceptConfig {
  readonly to: string | readonly string[];
  readonly view: RouteView;
}

type RouteIntercepts =
  Readonly<Record<string, RouteInterceptConfig>>;
```

Route-configured intercepts are keyed by slot name.

```ts
interface CallSiteInterceptInput {
  readonly slot: string;
  readonly view?: RouteView;
}

type InterceptInput =
  | false
  | string
  | CallSiteInterceptInput;
```

A string `InterceptInput` selects a configured slot. An object supplies a slot and optional view. `false` disables configured interception for one href/navigation call.

```ts
interface InterceptHistoryState {
  readonly __cookbookRouterIntercept: {
    readonly slot: string;

    readonly targetRouteId: string;
    readonly viewKey?: string;
    readonly previousHref: string;
    readonly context?: unknown;
  };
}
```

`InterceptHistoryState` is router-owned browser history state. Do not forge it manually.

```ts
interface ResolvedIntercept {
  readonly slot: string;
  readonly sourceRouteId: string;
  readonly targetRouteId: string;
  readonly view: RouteView;
  readonly previousLocation: string;
  readonly configured: boolean;
```

`ResolvedIntercept` is the normalized transition-time intercept state used by runtime and rendering integration.

## Normalized route contracts

```ts
interface RouteParamConstraint {
  readonly type: string;
  readonly params: string;
}

interface RouteParamDefinition {
  readonly name: string;
  readonly constraints: readonly RouteParamConstraint[];
  readonly wildcard: boolean;
  readonly optional: boolean;
  readonly token: string;
}
```

`RouteParamDefinition` is derived from route path tokens during normalization.

`token` preserves the full path token for diagnostics. `constraints` stores each constraint name and raw argument string.

## Match contracts

```ts
interface MatchedRoute {
  readonly id: string;
  readonly route: NormalizedRoute;
  readonly params: Record<string, unknown>;
}
```

```ts
interface RouteMatch<Route extends string = string> {
  readonly id: Route;
  readonly pathname: string;
  readonly search: Route extends RouteId
    ? RouteSearch<Route>
    : Record<string, string | readonly string[]>;
  readonly unknownSearch?: RouterUnknownSearchParams;
  readonly hash: Route extends RouteId
    ? RouteHash<Route>
    : string | undefined;
  readonly href: string;
  readonly route: NormalizedRoute;
  readonly branch: readonly MatchedRoute[];
  readonly params: Route extends RouteId
    ? RouteParams<Route>
    : Record<string, unknown>;
  readonly slots: ResolvedSlots;
  readonly intercepted?: ResolvedInterceptedRoute;
}
```

`RouteMatch` is the public matched-route state for the current or requested location.

When generated contracts are registered, `params`, `search`, and `hash` narrow by route ID.

## Preload contracts

```ts
interface RoutePreloadContext<
  Route extends string = string,
> {
  readonly route: MatchedRoute;
  readonly match: RouteMatch<Route>;
  readonly location: RouterLocation;
  readonly params: Record<string, unknown>;
  readonly search:
    | Record<string, string | readonly string[]>
    | Record<string, unknown>;
  readonly unknownSearch?: RouterUnknownSearchParams;
  readonly hash: string | undefined | unknown;
  readonly signal: AbortSignal;
}

type RoutePreload = (
  context: RoutePreloadContext,
) => void | Promise<void>;

type RouteModulePreload =
  () => void | Promise<void>;
```

`RoutePreloadContext.signal` is aborted when speculative work is superseded.

Preloading warms route work. It does not commit navigation, run middleware, or mutate router state.

| --------- | -------------------------------------------------------- |

## Where this bites

Do not hand-author `RouterContracts` unless integrating another generator.

The generated shape is coupled to route normalization, URL descriptors, path constraints, search/default semantics, hash policy, slot ownership, and emitted route IDs.

A manual approximation can compile and still disagree with runtime behavior.
